# BiliNote Studio 0.3.0 分阶段实施计划

> **给执行 Agent 的说明**：建议按阶段顺序（Phase 1 → Phase 2 → Phase 3 → Phase 4）逐任务执行，优先使用 `subagent-driven-development` 或 `executing-plans` 逐项落地并验收。所有步骤使用 `- [ ]` 追踪进度。每完成一个 Phase 建议向用户展示隔离预览并确认后再进入下一 Phase。

**Goal:** 为 BiliNote Studio 构建 `0.3.0` 升级版，彻底解决启动卡慢问题、完成兼容老数据的方案 1 后端领域重构与统一蒸馏队列/SSE 引擎，并在此基础上交付动态新建图标与三档完成提醒、单篇原声回看与原文/导图联动（方向 A）、主动复习闭环与 Anki/Obsidian 导出（方向 B）以及多 P 合集/本地字幕/批量升级（方向 D）。

**Architecture:** 后端以 `core/runtime.py` 收口路径与配置，重型依赖（`yt_dlp`、`chromadb`、`langgraph`、`faster_whisper`、`openai` 等）全量懒加载实现冷启动秒起；新建 `jobs/` 统一任务队列引擎与 SSE 事件流 `/api/jobs/events`，收敛 `llm/` 模型网关并拆出 `domains/` 业务域，同时 100% 保留既有 `bili_note.db`、`records-v2` 与旧路由兼容。前端拆包瘦身首屏 JS（≥55% 降幅），以 `distillQueueStore` 驱动导轨动态新建图标、强调色数字球、毛玻璃队列面板与三档提醒状态机，再依次接入方向 A/B/D。

**Tech Stack:** FastAPI / Python 3.11 (`E:\AI-Tools\BiliNote-build\python311\python.exe`) / SQLite / SSE；React 19 / TypeScript / Vite 6 (`pnpm.cmd` / `npx.cmd`) / Zustand / Tailwind CSS v4；Tauri 2 (Rust)。

- **正式安装红线**：未经用户另行明确授权，严禁修改、停止、重启或覆盖 `E:\AI-Tools\BiliNote`（端口 `8483`）及外部受保护目录；开发运行必须隔离端口、API 地址、数据与缓存目录。
- **数据兼容红线**：100% 兼容现有 `bili_note.db`、`note_results`（`records-v2`）、DPAPI 凭据与 Organizer 会话/保留/撤销契约，不做破坏性迁移。
- **提醒默认值**：完成提醒三档模式为 `'all_done' | 'each' | 'off'`，**默认值严格为 `'all_done'`（蒸馏完所有再提醒）**。
- **UI/UX 红线**：遵守 `.agent/rules/bilinote-ui-guide.md` 与 `AGENTS.md`（少文字、高透毛玻璃、动态强调色、`--ease-spring`、完整减动效守卫、`.quiz-anchor-slot` 禁设 `z-index`、`.morph-quiz` 禁设 `will-change: width, height`、费用/不可逆操作必确认）。
- **Windows 工具链约定**：前端命令使用 `pnpm.cmd` / `npx.cmd`，后端测试使用 `E:\AI-Tools\BiliNote-build\python311\python.exe`，检索未跟踪文件使用 PowerShell `Select-String`。
- **预览管理**：任何时候只保留一个隔离验收预览并在 `docs/PREVIEW_STATUS.md` 登记，验收完毕按任务 ID 精确停止。

## Review Focus

- **冷启动历史任务防误报**：应用冷启动或 SSE 断线重连拉取 `snapshot` 时，已处于 `SUCCESS` / `FAILED` 的历史任务绝不能触发 `'each'` 或 `'all_done'` 弹窗提醒。
- **后端懒加载不遗漏异常与类型边界**：把 `yt_dlp` / `chromadb` / `langgraph` / `faster_whisper` 延后导入后，若用户环境缺失可选依赖（如未装本地 Whisper 或快速版），必须返回明确中文可读错误而非 `500 ImportError` 崩溃。
- **SSE 断线与并发取消一致性**：SSE 短暂断连、用户连续快速点击取消或对同一篇笔记触发重新生成时，队列活跃计数（数字球）不得出现负数、幽灵残留或重复扣减。
- **无本地媒体与旧版纯 Markdown 笔记降级**：当旧笔记无本地音视频缓存、或非结构化纯 Markdown 笔记时，点击时间戳、思维导图、原文联动与 Anki/Obsidian 导出必须优雅降级，不得报错或白屏。
- **批量入队费用确认与部分失败隔离**：合集批量提交或旧笔记批量结构化升级时，必须先展示清晰确认提示；单条失败不得阻断同批次后续任务，且支持失败单项重试。
