# BiliNote Studio `0.4.0` 总升级规划

编制日期：2026-11-22  
定位：从「视频笔记工具」升级为「多源知识捕获 × 沉浸学习内化 × 桌面原生效率」的个人学习工作台  
兼容红线：100% 兼容既有 `bili_note.db`、`records-v2` 存储、Windows DPAPI 凭据与 Organizer 契约；公开 Windows 安装包继续严守零 AGPL 依赖（禁用 `PyMuPDF / fitz`）与零私有文件红线。

---

## 一、架构前置与多源内容接入（Phase 1）

### 1. 代码解耦前置（防大文件膨胀）
- **前端 `NoteForm.tsx` 拆解**：
  - 将 URL 提取、追踪参数清洗、平台自动识别与平台注册元数据抽离为独立模块 `BillNote_frontend/src/utils/sourceUrl.ts`（统一管理 `bilibili / youtube / kuaishou / x / xiaoyuzhou / web / local`），让新增平台只需在单一注册表追加配置，避免在 `NoteForm.tsx`、`constant/note.ts` 等多处散落硬编码。
- **后端 `note.py` 素材获取解耦**：
  - 梳理素材获取接口契约：区分 `media_kind = "video" | "audio" | "text_post"` 与可选 `post_context`、`local_images`；
  - `text_post` 路径统一跳过音视频下载、语音转写与 FFmpeg 视频截图，直接进入结构化笔记生成与本地插图/视觉理解流程。

### 2. 默认输出语言约束与轻量开关
- **补齐结构化提示词语言约束**（[prompt.py](../../backend/app/gpt/prompt.py) / [prompt_builder.py](../../backend/app/gpt/prompt_builder.py)）：
  - 在 `STRUCTURED_NOTE_INSTRUCTIONS`、`KNOWLEDGE_ATOM_PASS1_INSTRUCTIONS`、`KNOWLEDGE_CONSOLIDATE_PASS2_INSTRUCTIONS`、`KNOWLEDGE_CARD_BATCH_MERGE_INSTRUCTIONS` 与 `TUTORIAL_STRUCTURED_MERGE_INSTRUCTIONS` 中统一加入显式语言规则；
  - **默认简体中文**：标题、主干正文、表格、详注与自测题均使用简体中文；代码、命令、API/参数名、产品专有名词与英文界面原菜单项保留原文；
  - 支持 `output_language = "zh-CN" | "source"`（默认 `"zh-CN"`；当用户在「整理偏好 `extras`」中明确要求其他语言时优先生效）。
- **前端设置项**（[General.tsx](../../BillNote_frontend/src/pages/SettingPage/General.tsx)）：
  - 在「常规 → 工作区」新增「笔记输出语言」选择器：`默认简体中文` / `跟随原文`。

### 3. X（原 Twitter）全形态支持（已拍板定稿）
> 详细逐文件设计与测试清单见专项文档 [2026-11-22-x-platform-support-plan.md](2026-11-22-x-platform-support-plan.md)。

- **双通道覆盖**：
  - **视频推文 / Broadcast / Spaces**：复用 `yt-dlp`（内置 6 个 Twitter 提取器）+ `ProxyConfigManager` 全局代理 + 可选 X Cookie（从 `CookieConfigManager` 运行时转为临时 Netscape cookiefile 并在结束清理），同时融合推文正文与引用推文作为 `post_context` 背景上下文；
  - **纯图文推文 / X Article 长文**：无视频流自动降级提取正文与引用推文，直接跳过下载与转写直出结构化笔记。
- **配图本地化与视觉理解**：
  - 经全局代理将推文配图落盘至 `static/screenshots/x_<id>_<idx>.*`（上限 6 张，永久防墙外图链失效）；
  - 开启「视觉理解」时直接编码复用 `video_img_urls` 传给多模态模型；开启「自动配图」时直接插图且**零 FFmpeg 依赖**。
- **链接清洗与节奏**：
  - 支持 `x.com` / `twitter.com` / `mobile.twitter.com` / `fxtwitter.com` / `vxtwitter.com` / `fixupx.com` / `t.co`，仅针对 X 剥离 `s / t / ref_src / ref_url`（不误伤 YouTube `t=`）；
  - 单条推文/长文先行；同作者 Thread 串推自动拼接与书签/列表批量导入作为后续增量。

### 4. 复用同套底座拓展高频来源
- **小宇宙播客（`xiaoyuzhoufm.com/episode/...`）**：
  - 重写现有的实验草稿 [xiaoyuzhoufm_download.py](../../backend/app/downloaders/xiaoyuzhoufm_download.py)（移除顶层模块级网络请求，修复旧模型导入），解析单集音频直链、标题、封面、时长与 Shownotes 简介，归类 `media_kind="audio"`，直接接入单实体音频条回看与转写。
- **通用网页技术文章（博客 / 公众号 / Substack / GitHub README）**：
  - 复用已具备 SSRF 与公网 IP 安全防护的 [web_page.py](../../backend/app/services/web_page.py)（补充走全局代理通道），提取正文 Markdown/纯文本与标题，归类 `media_kind="text_post"` 直出结构化笔记。
- **本地 PDF / Markdown / TXT 文档拖入直出**：
  - 扩展 `NoteForm` 本地拖入与 `local_downloader.py`：`.md` / `.txt` 直接读取；`.pdf` 采用 **BSD 许可纯 Python 库（如 `pypdf`）** 抽取文本（严格避开公开安装包禁用的 AGPL `PyMuPDF / fitz`），免转写直出结构化笔记。

## 二、学习内化闭环深化（Phase 2）

### 5. 读者自建批注 + 助手回答「一键沉淀为正文批注」
- **持久化契约**：扩展每篇笔记的 `_meta/learning_state.json`，新增 `user_annotations` 列表（锚定 `section_id` + 句段定位 + 批注标题/详情 + 来源标记 `manual | assistant`），完全与 AI 生成的版本正文解耦（不破坏原版本快照，重生成或升级时可按节保留）。
- **前端交互**（遵循 Apple HIG 毛玻璃规范）：
  - 阅读正文划词浮条新增「记批注」，生成独立样式的句末个人批注锚点（点击弹出毛玻璃卡片，支持编辑与删除）；
  - 右侧阅读助手每条有效回复底部新增轻量操作「沉淀为正文批注」，自动关联当前引用章节/段落并挂入正文锚点，让笔记随提问持续进化。

### 6. 复习本轻量间隔重复（SRS）
- **数据结构扩展**：在 `learning_state.py` 的错题（`quiz_attempts`）与避坑（`pit_statuses`）条目中向后兼容扩展 `next_review_at`、`interval_days`、`ease`（轻量阶梯：`1天 → 3天 → 7天 → 21天`，答错回退至 `1天`）。
- **复习本体验**（`ReviewBankDialog.tsx`）：
  - 新增「今日到期」默认优先筛选标签与顶部极克制的待复习数量徽标；
  - 复习完成或重练答对时平滑推进下一次复习日期，保留手动「标记已掌握 / 重新复习」控制权。

### 7. 专题综合自测与库内相关笔记推荐
- **专题综合自测**：在笔记库或复习本支持按文件夹/多选笔记抽取章节 `quiz` 发起限时/无压力综合小测，作答结果自动回写各篇笔记的 `learning_state.json` 错题池。
- **库内相关笔记推荐**：基于现有 `vector_store.py` 向量检索与标签相似度，在阅读页文末或目录底部轻量展示 `2~3` 篇「库内相关笔记」（无检索结果或低相似度时静默隐藏，不强行凑数）。

## 三、桌面原生效率与资产管理（Phase 3）

### 8. 全局快捷捕获（Quick Capture）
- **Tauri 桌面端**（[lib.rs](../../BillNote_frontend/src-tauri/src/lib.rs) / `desktop.rs`）：
  - 在现有系统托盘菜单新增「从剪贴板一键蒸馏」动作；
  - 新增可配置的全局快捷键（如 `Alt+Shift+B`，支持在设置页开启/关闭），读取剪贴板识别受支持链接（B 站 / YouTube / X / 小宇宙 / 网页），无需拉起主窗口即可直接提交到后台 SSE 蒸馏队列，并由现有三档提醒通知完成。

### 9. 全局命令面板（`Ctrl+K`）
- 轻量苹果风毛玻璃命令面板组件：支持 `Ctrl+K`（macOS `Cmd+K`）全局呼出，覆盖：
  - 模糊搜索本地笔记标题/正文并直达；
  - 跳转到当前笔记章节；
  - 快捷指令：打开复习本、新建笔记（自动识别剪贴板链接）、切换深浅主题、打开设置。

### 10. 低码率本地回看缓存策略
- 在「设置 → 常规」提供可选开关：**保留低码率本地视频回看缓存**（默认关闭或按 `7 天 / 30 天 / 上限 MB` 自动滚动清理）；
- 开启后对 B 站 / YouTube / X 视频笔记优先缓存轻量低码率本地副本，使阅读页可直接启用单实体卷帘悬浮播放器与实时字幕同步，同时严格控制磁盘占用。

### 11. 空间清理、整库备份与轻量检查更新
- **空间管理**（后端新增 `/api/system/storage` + 设置页「存储与维护」）：
  - 分类统计 `data`（临时下载音视频）、`note_results`（笔记正文与版本）、`static/screenshots`（截图与配图）、`vector_db` 占用体积；
  - 提供「一键清理临时音视频缓存」（带二次确认，严格保留笔记正文、截图、学习状态与数据库）。
- **整库 `.zip` 备份与恢复**：
  - 导出包含 `bili_note.db`、`note_results`、`config`、`static/screenshots` 的一致性备份包（显式提示是否排除 API 密钥/Cookie 凭据，默认不含明文凭据）；
  - 导入恢复前强制做结构校验与自动预备份，防止覆盖损坏。
- **轻量检查更新**（[about.tsx](../../BillNote_frontend/src/pages/SettingPage/about.tsx)）：
  - 显示当前应用版本号与「检查更新」按钮，按需只读请求 GitHub Releases `latest` 接口对比版本号，有新版时给出更新摘要与发布页直链（不静默自动下载覆盖）。

## 四、推荐分阶段交付节奏与验收门禁

| 里程碑 | 覆盖条目 | 独立可交付价值 |
| --- | --- | --- |
| **Milestone 4A（核心多源 + 语言底座）** | 条目 `1`（解耦）、`2`（默认中文提示词与开关）、`3`（X 全形态 + 配图本地化与视觉理解） | 立刻用上 X 视频/图文/长文笔记，彻底解决英文内容输出语言漂移 |
| **Milestone 4B（高频内容源拓展）** | 条目 `4`（小宇宙播客 + 通用网页文章 + 本地 PDF/MD 直出） | 覆盖播客、技术博客与本地文档，打通全形态个人知识输入 |
| **Milestone 4C（学习内化闭环）** | 条目 `5`（自建批注 + 助手沉淀）、`6`（复习本 SRS）、`7`（专题综合自测 + 相关笔记推荐） | 笔记从“静态阅读”进化为“可生长、可周期复习的知识网络” |
| **Milestone 4D（桌面效率与资产治理）** | 条目 `8`（Quick Capture）、`9`（`Ctrl+K` 命令面板）、`10`（低码率回看缓存）、`11`（空间清理/备份/检查更新） | 原生桌面效率拉满、长期运行磁盘可控且数据可迁移 |

### 统一验收门禁（每阶段通用）
- **冷启动与体积守卫**：后端 `create_app` 冷启动保持 `< 1.2s`、重型依赖 0 预载；前端首屏直载 JS 严格控制在预算内（`<= 1350 KB`）；
- **回归与隔离真跑**：每阶段补齐对应 `pytest` + 前端 `pnpm test:release`；涉及下载或模型生成时，在隔离端口与独立数据目录完成真实业务流程验收；
- **公开包合规**：不引入 AGPL 依赖、不打包私有数据、不触碰正式版 `E:\AI-Tools\BiliNote`。
