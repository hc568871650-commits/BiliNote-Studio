# BiliNote Studio 0.1.0-preview.31 预发行说明

本版是相对公开预发行版 preview.8 的累计更新，面向 Windows x64。preview.9 至 preview.30 为本地迭代，不代表分别公开发行。

## 笔记与阅读

- 新增全库和文件夹范围的正文查找，可定位命中位置；搜索、筛选和排序控件更紧凑。
- 阅读区与聊天区支持调整分栏宽度，笔记图片可加入当前聊天草稿；字体、正文宽度和专注阅读集中到阅读菜单。
- 右下角只保留后端状态与管理入口，移除独立的主题与后台运行浮层；外观仍可在设置中调整。
- 阅读问答中断、失败或刷新后可恢复原问题、引用和附件；恢复不自动发送，也不会覆盖新的草稿。
- 生成任务提供更清晰的阶段、诊断信息和保存恢复；新增取消生成，已有完整笔记版本保留。
- 新处理的本地视频从约 10% 处提取封面。来源分段标题保留，不再重复写入跨段说明句。

## 助手与模型

- 资料库助手支持明确选择全库、文件夹或指定笔记；目标不清楚时先澄清。移动和归档仍需审阅计划并确认。
- 阅读与资料库问答扩展模型协议、视觉能力检测和上下文设置；支持查看能力检测证据及历史记录。
- 增加按需外部检索、来源网页读取和过程记录，可按模型配置联网方式。回答与工作过程分别保存。
- 整理模型服务商设置及生成确认区，集中展示生成参数与费用配置。

## 安全与稳定性

- 上传使用随机保存名、音视频后缀白名单和分块写入；默认单文件上限为 4 GiB，超限或中断时清理本次半成品。
- 封面代理限制平台来源，拒绝本地和内网地址及不安全跳转，并限制图片大小和等待时间。
- 源码后端默认监听本机回环地址。长音频分块转写会在块间检查取消。
- 安装与卸载时不再按程序名强制结束同名进程，发现正在运行的程序会要求先退出后重试。
- 已发出的模型或转写请求可能继续运行并产生费用；取消后会丢弃晚到结果，不发布新的笔记版本。

## 安装与更新

更新前备份 `%LOCALAPPDATA%\BiliNoteStudio`。安装程序不包含用户配置、密钥或笔记，使用独立程序和数据目录。

本版不内置 FFmpeg、本地 Whisper 或 PDF 导出，也不支持抖音链接下载；本地视频仍可导入。外部模型和在线转写可能产生费用，相关内容会发送给配置的服务商。安装程序未签名时，Windows 可能显示未知发布者提示。

## 验证范围与限制

- 开发验收曾使用非私人短样例，实际完成上传、Groq 转写、DeepSeek 生成、保存、刷新读取及全文查找；另验证模型阶段取消后旧版本保留。
- 真实短样例不能代表远程平台下载、长视频、真实多段转写取消或所有模型服务商均已验证。
- 外网封面在本机的正向验收未通过；安全边界和本地封面已做定向检查。
- 全仓 TypeScript 检查仍有既有错误。密钥沿用现有配置存储方式，尚未迁移到系统凭据库。

最终候选安装包已完成全新安装、实际 preview.8 升级和数据保留检查，见[本次验收](0.1.0-preview.31-validation.md)。公开下载状态以仓库 Releases 页面为准。
