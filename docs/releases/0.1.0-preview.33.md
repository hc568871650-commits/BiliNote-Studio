# BiliNote Studio 0.1.0-preview.33 累计说明

本页记录自公开预发行 `0.1.0-preview.31` 之后合入并对齐至本工作区的桌面增量变化（`0.1.0-preview.32` 与 `0.1.0-preview.33`）。后端主体保持 `0.1.0-preview.31` 对齐版本。

## 0.1.0-preview.32：长笔记滚动、笔记切换与对话存储性能

- **长笔记滚动与渲染复用**：优化阅读段落/标题定位、Markdown 正文渲染复用及工具栏动画期间的位置补偿（`ReaderPane.tsx`、`MarkdownViewer.tsx`、`readingPosition.ts`）。
- **分记录原子持久化**：引入 `recordStorage.ts`、`recordStorageDriver.ts` 与 `readingSessionStorage.ts`，将选中笔记、任务记录与阅读对话按会话/字段/消息拆分持久化，并缓存历史消息渲染组件 `ReadingMessageItem.tsx`（`ChatPanel.tsx`、`readingAssistantStore.ts`、`taskStorage.ts`）。
- **存储维护与兼容回退**：在桌面外壳新增 `--storage-maintenance` 启动入口与静态页 `public/storage-maintenance.html`（`src-tauri/src/lib.rs`），支持无后端介入的存储读写与跨格式回退转换。

## 0.1.0-preview.33：数位板笔尖拖动正文与直接拖动控制

- **笔尖拖动平移正文**：新增 `src/utils/readerPan.ts`，在阅读区支持数位板笔尖按住正文直接上下拖动平移（`ReaderPane.tsx`、`readingPosition.ts`）。
- **直接拖动期延后布局更新**：直接拖动期间延后工具栏折叠与位置反馈同步，减少长正文拖动跳动。

## 验证与已知边界

- 源码工作区保留了配套升级的前端合成测试与内存垫片，以及构建、部署、存储兼容性维护脚本（`tools/`）。
- 全仓 TypeScript 既有历史检查边界及正式环境运行边界见 [接手说明](../AGENT_HANDOFF.md)。
