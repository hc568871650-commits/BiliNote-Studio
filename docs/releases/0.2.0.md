# BiliNote Studio 0.2.0 发布说明

**状态：已公开发布。** 下载见 [v0.2.0 Release](https://github.com/hc568871650-commits/BiliNote-Studio/releases/tag/v0.2.0)（Windows x64 安装包 `BiliNote-Studio-0.2.0-windows-x64-setup.exe`，`74,750,484` 字节，SHA-256：`28e2843f3494f578a0f8f0380eeb3457baa04a802656d063d8c7bf83868e4d93`）。

`0.2.0` 是自公开预发行版 `0.1.0-preview.31` 以来的首个正式里程碑版本，围绕**结构化深度阅读、主动回忆自测闭环、桌面视觉与微交互精修、按用途模型治理与 Windows 凭据安全**完成了系统性升级。

## 结构化阅读与主动自测

- **高透毛玻璃结构化阅读器（`StructuredNoteReader`）**：
  - 支持将高信息密度视频笔记以核心结论高亮、实线下划线、动态强调色波浪线、防挤压二维对比表与单行因果链呈现。
  - 底层原理（`why`）、原片实测案例（`case`）与高频避坑细节（`pit`）收敛为句末 1:1 柔光批注锚点，悬停呈现单行预览气泡，点击展开半透明毛玻璃详注卡片，对下方正文零排版挤压。
- **原位膨胀自测胶囊与三级判题**：
  - 章节末尾默认折叠轻量自测胶囊，点击从左上角原点平滑膨胀展开，无排版跳动。
  - 作答后锁定选项并呈现三级视觉区分（正确答案淡强调色、用户误选柔红标叉、干扰项置灰删除线）与参考解析，配套可勾选核对清单。
  - 底部提供「去问助手」一键追问按钮，自动将题干、用户误选项、正确解析、当前章节正文与原片时间戳注入阅读助手输入框。
- **已有笔记一键结构化升级与学习闭环**：
  - 新增 `/api/notes/{task_id}/upgrade-structured`，可将已有 Markdown 笔记升级为结构化视图并保留历史版本。
  - 新增学习进度与作答持久化（`/api/notes/{task_id}/learning-state`）及跨笔记错题与高频避坑复习本（`/api/learning/review-bank`）。
  - 支持 Range 媒体流回看，提升本地视频时间戳跳转体验。

## 界面交互与动效升级

- **Codex × Apple HIG 桌面工作台精修**：
  - 笔记本侧栏图标支持动态开合动画；宽屏状态下展开/收起侧栏不再引发正文横向晃动。
  - 顶部阅读百分比预留稳定宽度，数值变化不再挤压邻近图标；大纲/段落选块采用零占位指示设计。
  - 阅读助手面板开关动画优化为更利落的阻尼节奏，支持自由拖拽宽度。
  - 导航栏切换（新建、笔记、助手、设置）与笔记筛选控件补齐连贯的过渡动画。
- **放射性明暗模式切换**：
  - 深浅主题切换以点击按钮为中心执行放射性扩散/收回（浅切深扩散、深切浅收回），基于纯百分比 View Transitions 裁切，高分屏无跳帧闪烁，并尊重 `prefers-reduced-motion` 设置。
  - 全站支持 8 组预设强调色与自定义强调色，高亮、波浪线与批注锚点均动态联动。

## 模型治理与安全增强

- **分用途默认模型（`/api/ai_purposes`）**：在「设置 → 模型与 API」集中为笔记生成、阅读问答、资料库助手分别配置默认服务商与模型，并兼容多协议能力检测与按需联网检索。
- **Windows DPAPI 凭据保护**：新增 `backend/app/utils/secret_store.py`，Windows 环境下服务商 API 密钥默认经当前系统用户 DPAPI 加密后存储，降低本地明文泄露风险。

## 安装与升级说明

- 本版提供单一 Windows x64 NSIS 安装包 `BiliNote-Studio-0.2.0-windows-x64-setup.exe`，应用标识 `com.bilinote.studio`，后端端口 `38484`，数据目录 `%LOCALAPPDATA%\BiliNoteStudio`。
- 更新前建议备份 `%LOCALAPPDATA%\BiliNoteStudio`。安装与卸载不会按文件名强制结束其他目录中的同名程序，如检测到正在运行请先退出应用后重试。
- 公开安装包不内置 FFmpeg、本地 Whisper、PDF 导出（PyMuPDF）或抖音链接下载；外部模型与在线转写服务由用户自行配置并承担对应费用。
- 安装程序未进行商业代码签名，Windows SmartScreen 首次运行可能弹出未知发布者提示，请先对照 `SHA256SUMS.txt` 核验完整性。
