# BiliNote Studio 0.4.0 发布说明

**状态：已公开发布。** 下载见 [v0.4.0 Release](https://github.com/hc568871650-commits/BiliNote-Studio/releases/tag/v0.4.0)（Windows x64 安装包 `BiliNote-Studio-0.4.0-windows-x64-setup.exe`，`79,512,899` 字节，SHA-256：`235e5d4673ad93836c6dd5618ad2413a912656418836cd19a03532f7465f5882`）。

`0.4.0` 是面向**全源知识输入、双语沉浸回看、深度阅读批注复习闭环与桌面原生数据主权**的全面里程碑升级，完整保持与 `0.3.0` 存储结构及凭据 100% 兼容。

## 多源输入扩展与默认简体中文

- **X / Twitter 双通道与多视频无缝拼接**：支持图文推文（配图本地化）与视频推文自动识别；主推文 + 引用短视频（或同推多视频）在本地经 FFmpeg 统一画幅自动拼接为连续单视频，音轨零网络秒抽，进度条自带可点击截断小白点精准跳至分段起点。
- **更多知识输入源**：新增**小宇宙播客单集**、**通用技术文章网页**（`beautifulsoup4` / `lxml` 正文提取）与**本地 PDF / Markdown / TXT 文档**直出（PDF 解析采用纯 Python BSD-3-Clause `pypdf 7.1.1`，零 AGPL 依赖）。
- **URL 识别解耦与默认简体中文**：自动识别链接来源平台；所有结构化与普通笔记默认输出简体中文（支持随时切换为“跟随原始语言”）。

## 双语字幕翻译与悬浮播放器体验精修

- **外语字幕双语翻译与专用翻译模型**：中文笔记生成时自动为外语视频静默翻译双语字幕并永久落盘缓存；支持在「设置 → 模型与 API」单独配置**字幕翻译模型**（如免费/轻量模型，默认跟随主模型）；原文面板与播放器均支持「双语 / 仅中文 / 原文」切换、增量补译缺失段落及右键 / 按钮一键重译。
- **播放器手感全面精修**：
  - 本地视频默认展开且首帧原地轻浮现（彻底消除打开飞移）；关闭后阅读区左下角保留高透毛玻璃速开圆钮；
  - 展开/收起时底座与靠边侧 0px 静止纯对角缩放；右上角关闭钮与四角缩放热区完全解耦零重叠；
  - 鼠标移出播放器 `2 秒`后悬浮播放栏与关闭钮自动淡出（并清除内部残留焦点，不收起视频画面），字幕平滑落回画面底部；
  - 收起态顶部悬浮字幕依停靠侧向内舒展自然折行并支持双语主副行。

## 深度阅读批注、复习 SRS 与桌面原生效率

- **正文个人/助手批注与 SRS 复习调度**：划词即可记句末批注或一键沉淀助手解答；复习库升级为间隔重复（SRS）到期调度；新增**专题综合自测**（跨笔记汇总出题）与**相关笔记**语义推荐。
- **桌面原生效率与数据主权**：新增全局快捷键捕获与系统托盘一键蒸馏、`Ctrl+K` 命令面板、GitHub Releases 检查更新；新增「设置 → 存储与维护」页，提供 macOS 风格浅/深色自适应分类占比分布条、一键清理临时音视频缓存（含 `.clips.json`）及整库 `.zip` 备份恢复（默认不含 API Key / Cookie 明文，恢复前自动预备份）。

## 安装与升级说明

- 本版提供单一 Windows x64 NSIS 安装包 `BiliNote-Studio-0.4.0-windows-x64-setup.exe`，应用标识 `com.bilinote.studio`，后端端口 `38484`，数据目录 `%LOCALAPPDATA%\BiliNoteStudio`。
- 从 `0.3.0` 或更早公开版升级前建议先备份 `%LOCALAPPDATA%\BiliNoteStudio`，从托盘退出正在运行的 Studio 后直接覆盖安装即可，用户数据与数据库自动保留。
- 公开安装包不内置 FFmpeg、本地 Whisper、PyMuPDF（AGPL）或抖音链接下载；外部大模型与在线转写服务由用户自行配置并承担对应费用。
- 安装程序未进行商业代码签名，Windows SmartScreen 首次运行可能弹出未知发布者提示，请先对照 `SHA256SUMS.txt` 核验完整性。
