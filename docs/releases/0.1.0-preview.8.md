**状态：已公开预发行。** 发布日期：2026-10-12。本文汇总相对公开 `0.1.0-preview.1` 的累计开发更新；`preview.2` 至 `preview.7` 是本地迭代记录，不代表分别公开发布过安装包。

## 本次更新

### 教程蒸馏与局部修订

- 新生成流程集中为“教程笔记”和“知识笔记”：分别关注操作对象、顺序与参数，或概念、因果与例子。历史风格名称仍可读取。
- 目录从正文标题生成，生成选项更精简；配图和画面理解独立控制。
- 动态取帧结合画面变化、稳定状态、字幕提示与去重，记录实际帧时间，改善固定间隔采样遗漏短暂操作的情况。
- 图片、时间标记与字幕范围按实际来源对应，版本保留必要的来源证据；小图网格不再无谓放大。
- 连续选段可局部重新蒸馏：依据原始字幕及可用画面生成修订，先查看新旧内容与来源，再采纳为新版本。旧正文与旧图保留。

### 生成可靠性、用量与对照

- 生成进度显示来源名称、当前阶段、耗时和具体错误；成功或失败后停止活动计时，重开页面仍能查看已保存状态。
- 长视频按时间、字幕长度和请求规模分片，保存完整分片作为恢复依据。截断、空正文和不完整合并不会被当作完整结果保存。
- 明确区分请求过大、输出截断与普通失败，限制重试及总请求预算；丢失受理响应时核对原请求 ID，减少重复提交。
- 生成详情记录逻辑请求和实际尝试、输入/输出/思考/缓存用量、耗时、结束原因及实际参数；缺失或矛盾字段明确展示，不将未知当作零。
- 可设置思考档位、温度、输出上限、分片和重试预算，显式保存模型默认值，并根据填写的单价估算费用。
- 增加两方案对照：冻结同一份字幕及可用图片，保存独立结果与来源指纹，支持恢复查看和取消后续请求，不覆盖原笔记。
- 调整生成提示词的公共前缀顺序并记录缓存用量，为服务商缓存创造复用条件；不保证命中率或节省比例。

### 阅读、引用与桌面界面

- 目录支持分组/全部、搜索、当前位置、快捷横条和章节标记；窄窗口采用覆盖式目录。
- 修复切换笔记或版本时目录槽位晚出现、正文横向弹动的问题。首帧确定占位，并使用有效版本 ID 避免重复挂载。
- 修复滚动条拖动时间较长、目录跳转后立即手动滚动时详情栏漏收起的问题。
- 详情栏与阅读工具增加收起/展开过渡和箭头旋转，动画期间补偿阅读位置，支持减少动态效果。
- 一次选段中的多个段落按原文顺序合为一份引用；每条消息仍最多 8 份引用或附件。
- 笔记“⋯”改为紧凑浮层，集中常用管理、导出与详情操作；已有笔记的生成设置使用小窗，关闭后继续阅读。
- 更新一体化标题栏、单色应用图标、紧凑工作区边框与设置页间距；阅读聊天的联网入口收纳至聊天设置。

### 模型能力与资料库助手

- 阅读、资料库问答、整理计划与压缩遵循服务商协议设置，支持 Chat Completions、Responses 和 Anthropic Messages。视频总结仍使用 Chat Completions 兼容路径。
- 按模型检测基础回复、流式、工具、联网及候选思考档位，显示结果、时间与证据；主动测试会产生模型请求，读取已有记录不会。
- 阅读问答可显式启用已验证的原生搜索或配置的 SearXNG，返回结构化来源。资料库助手当前界面不启用联网搜索。
- 资料库助手可按关键词检索本地正文，分章节、按版本或转录片段读取，并结合多篇笔记回答，附可打开的来源。
- 只读查询与整理写入范围分离。归档资料可被查询，但整理修改仍需明确计划与用户确认；不开放永久删除、改写正文或任意本地文件操作。
- 错误保留可用的脱敏 HTTP 状态、请求 ID、协议和时间，不静默换模型或协议。

## 使用与更新提示

- 本次目标仍是单一 Windows x64 安装版。公开首发的数据目录为 `%LOCALAPPDATA%\BiliNoteStudio`，与程序目录分离；升级前备份该目录。
- 新安装包已重新核验分发边界：在线转写、外置 FFmpeg，不内置本地 Whisper、PDF 导出或抖音链接下载。
- 本机专用桌面更新程序不能作为通用安装包上传，也不应直接覆盖其他用户的独立 Studio 安装。
- 局部重蒸馏、对照测试和模型能力检测会发送新的请求。停止本地等待或取消后续任务，不保证供应商已接受的请求停止计费。
- 资料库问答会将检索到的正文或转录发送给所选模型。关键词检索有读取预算，不代表全库语义向量检索或穷尽阅读。
- 历史笔记没有的生成用量不会自动补齐。对照目前使用最新版本的来源；局部重蒸馏需要保留原始字幕，画面能力还依赖可用视频或图片。
- 实时视频播放联动、自动质量评分、逐段语义差异高亮和对照结果一键替换正文不在本次已实现范围内。
