# BiliNote Studio 0.4.1 发布说明

**状态：已完成源码定版与本机正式版实装（待后续公开发布）。**

`0.4.1` 是面向 **`0.4.0` 静态配图视觉理解稳定性、阅读与失败状态机一致性及阅读顶栏防裁切** 的专项修复版本，与 `0.4.0` 数据库、笔记归档（`records-v2`）、复习记录及凭据存储保持 100% 兼容。

## 静态配图多模态视觉理解修复

- **消除静态配图与时间范围错配报错**：修复带图 X Article 等静态配图内容在开启「自动配图」与「画面理解」时，因所有文本段为 `0.0s` 无视频时间轴而触发 `ValueError: 视频图片与时间范围数量不一致，拒绝错配` 的故障。
- **双通道分块语义清晰分离**：静态配图经 `_prepare_local_image_evidence` 走预算顺序分块（落盘规范化为 `evidence.video_image_ranges == []`），二次合并（`pass2`）不重复发送图片；有时轴本地/在线视频的 `VideoReader` 动态抽帧链路继续保留精确时间范围对齐。

## 阅读/失败状态机、顶栏防裁切与确认守卫

- **失败与历史可读态无缝衔接**：
  - 首次生成失败且无正文时，主画布展示精简诊断与恢复卡片，顶栏零重复入口，无关工具栏按钮与 `Ctrl+.` 快捷键自动禁用；
  - 有历史可读正文的重生成进行中或失败时，主画布保持可读旧版与滚动位置，支持诊断弹窗内「重试保存」（基于 `save_recovery` 零模型请求直接恢复已生成正文）或付费重新生成。
- **顶栏单行防裁切**：优化阅读顶栏在 `1000px` ~ `1280px` 宽度且侧栏展开时的自适应收敛（756 组矩阵布局回归零裁切、零重叠、零误隐）。
- **明确费用确认守卫**：新增 `RegenerateConfirmDialog`，覆盖首次失败重生成、诊断弹窗重生成及蒸馏队列重试/取消操作，取消确认不发起任何模型请求，未知提交自动沿用同请求 ID 续交。
