# BiliNote Studio 0.4.2 发布说明

**状态：已完成源码定版与自动化回归，正在进行本机正式版实装及 Windows x64 安装包构建验收（待后续公开发布）。**

`0.4.2` 是面向 **`0.4.1` 长文/多段知识笔记二次合并（Pass 2）与教程合并出现裸 JSON 直接当普通正文渲染问题** 的专项修复版本，与 `0.4.0` / `0.4.1` 数据库、笔记归档（`records-v2`）、复习记录及凭据存储保持 100% 兼容。

## 结构化 JSON 生成、适配与落盘防护修复

- **统一注入完整 Schema v1 模板（根治提示词缺口）**：
  - 在 `backend/app/gpt/prompt.py` 中抽取唯一真源 `STRUCTURED_NOTE_SCHEMA_TEMPLATE`，统一接入 `STRUCTURED_NOTE_INSTRUCTIONS`、`KNOWLEDGE_CONSOLIDATE_PASS2_INSTRUCTIONS`、`TUTORIAL_STRUCTURED_MERGE_INSTRUCTIONS` 及 `UniversalGPT._repair_json_once`；
  - 同步补齐知识 Pass 2 与教程合并在开启 `screenshot` 时的 `STRUCTURED_SCREENSHOT_RULES`，避免长文合并阶段模型自行编造 `chapters` / `concept_block` / `comparison_table` 等非标准 JSON 结构。
- **幂等变体适配器与三阶段自测答案匹配（兜底兼容模型漂移）**：
  - 在 `backend/app/models/structured_note.py` 新增 `_coerce_variant_document` / `_coerce_variant_section`，无损适配 `chapters`、`summary`、`concept_block`、`comparison_table` / `param_table` / `troubleshooting_table`、单串箭头或字典形态 `flow_chain`、章节级嵌套局部批注 ID 防冲突以及顶层单/多道 `quiz` 保序挂载；
  - `_normalize_quiz` 升级为三阶段匹配（完整选项全等 → 独立/带分隔符标号 `A-D` → 唯一无歧义子串），杜绝首字符碰撞与反义子串误命中。
- **损坏裸 JSON 拒绝落盘红线**：
  - 在 `backend/app/gpt/universal_gpt.py` 新增 `_looks_like_unparsed_structured_json`，拦截无法解析的损坏/截断结构化 JSON（含未闭合 ```` ```json ```` 围栏与带前导语截断 JSON）退化为裸文本段落落盘，同时保持合法纯文本 Markdown 的正常回退。
