# BiliNote Studio 0.3.0 发布说明

**状态：已公开发布。** 下载见 [v0.3.0 Release](https://github.com/hc568871650-commits/BiliNote-Studio/releases/tag/v0.3.0)（Windows x64 安装包 `BiliNote-Studio-0.3.0-windows-x64-setup.exe`，`74,612,531` 字节，SHA-256：`f86a02d549d3e6290ab2390aa7f3dda72e59ea3e34cd408c0005f9c2c3ca95cc`）。

`0.3.0` 是继 `0.2.0` 后的全四阶段核心升级，围绕**单实体悬浮音视频回看、极速冷启动、无感后台蒸馏队列 SSE、课程级多 P 批量导入与字幕直出、沉浸复习闭环及 4 格式知识外带**完成全面迭代，并保持与 `0.2.0` 存储及凭据 100% 兼容。

## 单实体卷帘悬浮音视频播放器

- **音频与视频统一为单一实体（`MiniMediaPlayer`）**：默认收起为 `248×36px` 影院黑玻璃迷你音频条与无缝一体凹弧顶耳，内含顶部细丝进度轨、`-5s / 播放暂停 / +5s`、`CC / 1x / 静音 / 关闭`；实时字幕轻盈悬浮于顶耳上方，贴近阅读区顶边时自动下翻防裁切。
- **丝滑卷帘手势与防越界物理**：
  - 收起态按住顶耳上拉优先实时卷展为 16:9 视频（拉满瞬间无缝交接为 360° 全向自由拖框）；
  - 展开态全向自由拖框，触底后继续下拉一比一实时压扁收窄回 `248×36px` 音频条且音频不中断；
  - 配备近边高阻尼防越界墙、无过冲临界阻尼落点、四角受限 16:9 等比缩放、时间点点击直达、原文参照三向联动及 B 站 / YouTube 嵌入回看。

## 极速启动与无感后台蒸馏队列

- **冷启动与首屏体积优化**：后端 `create_app` 冷启动压降至约 `1.0s`（9 项重型依赖延迟加载，0 预载）；前端路由与重组件按需拆包，首屏直载 JS 控制在 `1350 KB` 预算内；Tauri 桌面端异步检测 FFmpeg。
- **后台 SSE 队列与导轨通知**：新增 `backend/app/jobs/` 任务总线与 `/api/jobs/events` 实时推送；左侧导轨新增动态镂空遮罩「新建笔记」图标与强调色数字球（仅新建页悬停预览，阅读页悬停静默防打扰），支持全部完成 / 逐条完成 / 静默三档提醒。

## 课程级批量生产、沉浸复习与知识外带

- **多 P 合集导入与 `.srt/.vtt` 字幕直出**：新增 `/api/ingestion/*` 合集懒加载解析、去重标记、自动建同名文件夹与费用确认批量入队；支持拖入本地 `.srt / .vtt` 字幕（UTF-8 / BOM / GBK），自动跳过下载与语音转写直接生成结构化笔记。
- **旧版笔记批量结构化升级**：笔记库支持多选旧版 Markdown 笔记，通过原生 `<dialog>` 费用确认弹窗调用 `/api/notes/batch-upgrade-structured` 后台批量升级，保留全部历史版本。
- **沉浸复习闭环与 4 格式导出**：跨笔记「错题与高频避坑」复习本支持整卡点击展开原位重练、翻卡自检、掌握流转（`ever_wrong / mastered`）及跨路由 `1.6s` 脉冲锚点直达；内置结构化现代思维导图；导出新增 **Obsidian 增强 Markdown**（YAML Frontmatter + Callout）与 **Anki `.tsv` 闪卡**。

## 安装与升级说明

- 本版提供单一 Windows x64 NSIS 安装包 `BiliNote-Studio-0.3.0-windows-x64-setup.exe`，应用标识 `com.bilinote.studio`，后端端口 `38484`，数据目录 `%LOCALAPPDATA%\BiliNoteStudio`。
- 从 `0.2.0` 或更早公开版升级前建议先备份 `%LOCALAPPDATA%\BiliNoteStudio`，退出正在运行的 Studio 后直接覆盖安装即可，用户数据与数据库自动保留。
- 公开安装包不内置 FFmpeg、本地 Whisper、PDF 导出（PyMuPDF）或抖音链接下载；外部大模型与在线转写服务由用户自行配置并承担对应费用。
- 安装程序未进行商业代码签名，Windows SmartScreen 首次运行可能弹出未知发布者提示，请先对照 `SHA256SUMS.txt` 核验完整性。
